# 2026-11-06 일일 보고서

1. **터미널 방치형 게임 구현**
   Go와 tcell로 급여가 현실 시간에 맞춰 쌓이는 게임을 만들었다. 급여 입력·플레이·결과 화면과 성과급 획득, 오후 6시 자동 정산을 구현했다.

2. **플레이 피드백 반영**
   입금 주기를 1분으로 조정하고 지폐 크기와 안내 문구를 개선했다. 종료 확인창을 추가하고 작은 터미널에서 문구가 겹치거나 잘리는 문제를 수정했다.

3. **문자 너비 계산 오류 수정**
   한국어 터미널에서 지폐 테두리와 게이지가 끊겨 보이는 원인을 조사했다. 문자 너비 계산을 출력 라이브러리와 통일하고 회귀 테스트로 확인했다.

4. **실행 파일과 npm 패키지 배포**
   Windows·Mac 실행 파일을 준비하고 npm 패키지 v1.0.3을 공개 배포했다. 패키징 과정의 Mac 실행 권한 문제를 수정하고 Windows에서 다운로드·플레이를 확인했다.

5. **npx 실행 오류 해결 및 문서 정리**
   프로젝트 폴더에서 npx가 같은 이름의 로컬 패키지를 선택하는 오류를 재현했다. `@latest` 지정으로 정상 실행을 확인하고 실행 안내와 작업 일지를 정리했다.
